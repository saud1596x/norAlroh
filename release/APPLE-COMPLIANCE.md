# متطلبات Apple المنطبقة على نور الروح

تمت مراجعة صفحات Apple الرسمية في ٥ أكتوبر ٢٠٢٦. هذه خريطة للمتطلبات المنطبقة على وظائف الإصدار الحالي وليست شهادة قبول أو ادعاء اكتمال كل متطلبات المتجر. إرشادات Apple تتغير، ويجب مراجعة النسخة النهائية وبيانات App Store Connect عند التقديم.

| المتطلب | التطبيق الحالي | ما يحتاج إثباتًا قبل التقديم |
|---|---|---|
| 1.1.5: دقة الاقتباسات الدينية | الآيات والبسملات من Tanzil دون تعديل، والأذكار مقارنة بمصدرها | تدقيق متخصص للنصوص والرسم، ومراجعة حالات QCF الـ٤٩ |
| 2.1: اكتمال التطبيق | مصدر SwiftUI أصلي ومزايا محلية دون شاشة تسجيل دخول تعطل الاستخدام | بناء Release وتوقيع وتجربة iPhone/iPad؛ لا توجد نتيجة Xcode بعد |
| 2.3: بيانات ولقطات دقيقة | وصف مزايا فعلية في المصدر، وصف المتابعة الصوتية كمقارنة كلمات محلية بفروق محتملة دون ادعاء تصحيح التجويد أو دقة لم تُختبر | استعمال لقطات iOS الفعلية واستبيان العمر الحالي ووصف نهائي بعد الاختبار |

| 4.8: خدمات تسجيل الدخول | لا توجد حسابات مستخدم أو تسجيل اجتماعي | إذا أضيف تسجيل اجتماعي، راجع وجوب خدمة مكافئة تحمي خصوصية الاسم والبريد؛ Sign in with Apple خيار معتاد، ولا يلزم لمجرد وجود تطبيق |

| 5.1.1(ii–iv): الأذونات وتقليل البيانات | الميكروفون عند بدء التسجيل، والإشعارات عند التفعيل، ولا إذن موقع أو تتبع | اختبار قبول الإذن ورفضه وسحبه على جهاز؛ تبقى القراءة متاحة بعد الرفض |
| 5.1.1(v): الحساب والحذف | التطبيق يعمل دون حساب؛ تصدير وحذف البيانات المحلية مع التأكيد | إذا أضيف إنشاء حساب، تنفيذ حذف الحساب وبيانات الخادم من داخل التطبيق؛ حذف البيانات المحلية لا يكفي |
| 5.1.2: مشاركة البيانات | لا مزامنة أو رفع صوت أو إعلانات؛ تحليل صوتي محلي وتنزيل النموذج بموافقة، والتصدير تحت تحكم المستخدم | فحص شبكة نسخة Release وكل SDK؛ إعادة الإفصاح والموافقة إذا أضيف طرف يتلقى بيانات |
| 5.2: حقوق المحتوى | نسبة المصادر وتراخيص Tanzil وأميري وAdhan وبيانات QCF وWhisperKit ونموذجه ومكوناته داخل التطبيق | إذن توزيع ملفات خطوط QCF مستقل عن MIT للبيانات، واستكمال موارد وحقوق تضمين ثمانية |

| أدوات الرفع | Xcode 26+ وSDK iOS 26+ في مسار البناء والفحص | نتيجة حقيقية للمسار؛ المصدر وحده لا يثبت الأداة المستخدمة |

## الحسابات: فرق مهم

حساب سعود في Apple Developer وApp Store Connect يستخدم للنشر والتوقيع، وليس حسابًا لمستخدم نور الروح. لا تضف اسم مستخدم أو تسجيل دخول أو زر «حذف حساب» وهميًا إلى تطبيق يعمل محليًا. الإعداد الحالي `userAccountMode: local-only`؛ سؤال إضافة حساب ومزامنة للمستخدم ما زال ينتظر اختيار سعود.

إذا اختيرت حسابات: يلزم مزود مصادقة وخادم فعلي، حفظ آمن للمفاتيح، سياسة مزامنة واحتفاظ، بدء حذف الحساب من داخل التطبيق وحذف البيانات المرتبطة، وإلغاء رموز Sign in with Apple إذا استُخدم. يُحدّث الإفصاح عن البريد والمعرّفات والتأملات وسجلات الحفظ وغيرها بحسب ما يصل للخادم. لا يوصف ذلك كميزة تعمل قبل التنفيذ واختبارها.

## أمور لا تنطبق على الوظائف الحالية

لا اشتراكات أو مشتريات داخل التطبيق أو شراء خارجي أو إعلانات، لذلك لا توجد واجهة دفع أو طلب تتبع ATT في الإصدار المحلي. لا مجتمع أو مشاركة عامة للمحتوى؛ التأملات خاصة ومحلية. لا يستلزم وجود التطبيق وحده إضافة كل هذه المزايا. إذا أضيفت لاحقًا تُراجع متطلبات الدفع والمحتوى العام والتتبع والحسابات المناسبة.

شاشة شروط الاستخدام أضيفت لتوضيح المراجعة الذاتية والمواقيت وحقوق الموارد. ليست تسجيلًا لموافقة المستخدم على جمع بيانات، ولا تحل محل أذونات النظام أو اتفاقية ترخيص Apple القياسية.
