# Independent reminder increment

Implemented: optional independent dua, morning/evening adhkar, salawat and Hifz schedules; start/end window, once or 2/4/6/12-hour repetition, weekdays and overnight quiet hours. Local Gregorian device-clock calendar, explicit DST missing/repeated-time handling, next seven-day dated requests, existing serial notification reconciliation and 64-request shared budget. Prayer requests retain priority; khatmah/foreign requests count against capacity and are never cancelled here. Remaining capacity is assigned to chronological personal events, with an honest partial-capacity message.

Explicit edits replace personal requests, reject unreadable stored data without overwriting, cancel disabled-category delivered reminders and skip already delivered event IDs. Salawat's original schedule/preferences remain in use until explicitly edited in the new editor, at which point only the new schedule is active. Full-data erasure cancels owned prayer/salawat/personal requests, preserving unrelated requests. Export schema11 includes the raw personal preference bytes. Existing startup/foreground/significant-time/background refresh paths also refresh personal reminders. No automatic extra reminder permission or opt-in is introduced.

Home/settings opens the new reminder hub. Notification routes open dua search, the bundled morning/evening adhkar section, salawat counter or actual Hifz review. The morning/evening section retains its original combined content and timing instructions, without rewriting Quran/adhkar text.

Separate practice listening assistance now increments only through the real AVPlayer-start callback for the current canonical verse, with saved/offscreen/stale callback guards; failed or invalid playback does not count. A native AAC playback test covers the real callback and production session helper. This is not recitation or pronunciation accuracy evidence.
